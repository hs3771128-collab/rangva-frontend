# Design references

Static HTML mockups used to define the Rangva look before it was built in React.

| File | Purpose |
| --- | --- |
| `rangva.html` | Approved unified storefront layout (fashion + beauty in one grid) |
| `fashion.html` | Fashion-only exploration |
| `beauty.html` | Beauty-only exploration |
| `contact.html` | Contact page layout |
| `contact-sheet.png` | Index sheet of the product photography used in the catalogue |

Open any `.html` file directly in a browser. These are reference-only and are not part of the app build.
